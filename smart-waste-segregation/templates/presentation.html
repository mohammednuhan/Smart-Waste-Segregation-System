PART 1 — Introduction & Problem (30 sec)

🗣️ Say: "Good morning ma'am. Our project is EcoSort — a Smart Waste Segregation and Recycling System, built for the topic Conservation of Natural Resources.

India generates about 62 million tonnes of waste every year, but most of it isn't segregated properly. People often don't know which bin an item belongs to — so recyclable waste gets polluted, and landfills keep filling up. We built EcoSort to solve exactly this confusion, using technology."

  • Point to nothing yet — just stand at the home page.
  • Hook: "Instead of guessing, users can now simply type an item and get the correct answer instantly."
PART 2 — THE LIVE DEMO (60 sec) ⭐ Most Important

This is the most impressive part. Do these three searches slowly, reading results aloud.

SEARCH #1 — "banana peel"

Type banana peel slowly. Pause so the live suggestion pops up, then press Enter.
🗣️ Say: "Here you can see the live search suggestion working in real time. EcoSort classified it as Organic / Wet Waste, Green Bin. It tells me to compost it, that it decomposes in 2–3 weeks, and that it's rich in potassium and phosphorus."

SEARCH #2 — "battery"

Clear and type battery, press Enter.
🗣️ Say: "Now a hazardous item. EcoSort correctly sends it to the Red Bin — special collection. It warns that batteries contain toxic chemicals like mercury and lead, and tells users never to mix them with regular waste. This prevents contamination of soil and groundwater."

SEARCH #3 — "plastic bottle"

Clear and type plastic bottle, press Enter.
🗣️ Say: "Plastic bottle — Recyclable, Blue Bin. Notice it shows the environmental impact: it takes 450+ years to decompose, but recycling it turns it into polyester fibre. So recycling isn't just convenient, it's essential."

  • After the 3 searches point out: "Each result shows the correct bin colour, how to dispose it, decomposition time, environmental impact, and step-by-step recycling process."
  • Mention coverage: "The system knows 85+ everyday items across 5 categories — and the result includes a 'bin badge' so even colour-coded bins are clear."

PART 4 — Tech & Closing (20 sec)

🗣️ Say: "Under the hood, EcoSort is built with Python and Flask on the backend, SQLite for storing classification history and statistics, and a responsive frontend with HTML, CSS and JavaScript. It's designed to work on a phone, right in the kitchen.

In the future, we plan to add image recognition, machine-learning accuracy improvements, user accounts, and integration with local waste collection schedules. Thank you, ma'am — I'd be happy to take any questions."

Expected Questions & Answers ⭐ Read Once Before Presenting
How does the classification actually work?

Answer: "When you type an item, the backend searches a database of 85+ items. It looks for an exact match first, then a partial match — for example 'bottle' can match both plastic bottle and glass bottle. On a match, it returns the full disposal guide with bin colour, decomposition time and recycling process."

What happens if an item is not in the database?

Answer: "It shows a friendly 'not found' message with helpful tips — like trying simpler terms — so the user is never left confused. We can demonstrate that too."

💡 If asked, demo typing "random junk" on the home page.

What data do you store?

Answer: "We store the item name, its category, the recommendation we gave, and the timestamp — in a SQLite database. We use this only for the statistics dashboard, no personal data."

Is this relevant to India's waste rules?

Answer: "Yes. The categories follow the CPCB Solid Waste Management Rules 2016, which require households to segregate wet, dry and hazardous waste at the source. EcoSort teaches people exactly how to do that."

Why is source segregation important?

Answer: "Up to 80% of waste could be recycled or composted if it's segregated properly. Mixed waste is very hard to recycle — one contaminated bin can spoil an entire batch. Segregation at home is the cheapest, most effective step."

What are the future enhancements?

Answer: "Image recognition to identify waste by photo, machine learning for better accuracy and more items, user accounts for personal tracking, local collection schedule integration, and multi-language support."
