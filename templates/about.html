About

Smart Waste Segregation.
Built for a Sustainable India.

EcoSort is an AI-powered waste classification system developed as part of the Conservation of Natural Resources course — bringing proper waste management to every household.

Project Overview
  • Subject: Conservation of Natural Resources
  • Year: 2026
  • Type: Web Application
  • Audience: The general public
Objective & Problem Statement

Objective: To develop an intelligent system that helps users correctly classify waste into proper categories (wet/organic, dry/recyclable, hazardous) with clear disposal and recycling guidance.

The Problem: India generates approximately 62 million tonnes of waste annually, yet only ~75–80% is even collected — and a large share isn't segregated. This leads to:

  • Environmental pollution & groundwater contamination
  • Health hazards from burning unsegregated waste
  • Greenhouse gas emissions from landfills
  • Marine ecosystems threatened by plastic waste

What It Does

Key Features

Everything you need to segregate waste correctly and spread the habit.

Instant Classification

A database of 85+ everyday items across 5 categories. Just type, and get the answer instantly — no waiting.

Disposal Guidance

Each item comes with the correct bin colour, disposal method and a step-by-step recycling process.

Impact Tracking

Every classification is logged, so you can see real usage statistics and which items people search most.

Educational Content

Learn the SWM Rules 2016, understand waste types and discover how recycling actually works.
